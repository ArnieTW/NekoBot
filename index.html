Streaming overlay companion

Build HTTP overlays, bind triggers, and keep stream effects under control.

NekoBot provides browser-source overlays for tools like OBS, Streamer.bot integration, source management, and optional local TTS support.

Download latest release Read documentation View examples

HTTP Overlays

Create overlay layouts and open them as browser sources in OBS or any streaming software that supports web overlays.

Trigger Binding

Bind boxes to Streamer.bot events, commands, and actions, then route the selected source when a trigger arrives.

Local Setup

Configure overlays, sources, Streamer.bot, logs, and TTS from the local setup interface.

Get Started

Download a release package, run NekoBot, then open the setup page from the tray menu. From there you can create overlays, connect Streamer.bot, and copy overlay URLs into OBS.
