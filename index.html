NekoBot stream overlay engine

Supercharge your stream and viewer experience with highly customizable OBS overlays.

NekoBot lets you build one full-scene browser overlay, fill it with triggered text, media, audio, video, and TTS boxes, then drive those effects from Twitch, Kick, Streamer.bot, chat commands, channel rewards, and local action flows.

Overlay Studio

Create one full-scene browser overlay in OBS, then place triggered boxes inside it for memes, alerts, captions, sound cues, videos, and TTS moments.

Connectors

Connect Streamer.bot, Twitch, and Kick so NekoBot can receive chat, reward, command, and platform events.

Command Triggers

Create NekoBot triggers, add cooldowns, bind connector events, and drive overlay boxes, chat replies, waits, logic, and other action chains.

Get Started

Download a release package, run NekoBot, then open the setup page from the tray menu. From there you can connect platforms, create one overlay for a stream scene, add boxes for different triggered effects, monitor chat, define channel rewards, and copy the overlay URL into OBS.
