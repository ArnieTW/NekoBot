Integration

Streamer.bot Setup

Streamer.bot provides the events that NekoBot can bind to overlay boxes.

Connection

  1. Enable the Streamer.bot WebSocket server.
  2. Open NekoBot setup and choose Streamer.bot setup.
  3. Enter the host, port, and password if configured.
  4. Connect and subscribe to the event groups you want to use.

Triggers

Triggers can represent raw subscribed events, commands, or actions. Use Overlay Setup to bind a trigger to a box.

  • Use chat-message triggers for regular chat overlays.
  • Use command triggers for commands such as !tts or !clip.
  • Use action triggers when Streamer.bot actions should drive an overlay.
