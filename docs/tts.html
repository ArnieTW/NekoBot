Voice

TTS Setup

NekoBot can use local TTS models for generated voice sources when enabled.

Model Setup

  1. Open TTS Setup.
  2. Enable a model.
  3. Choose backend settings such as CPU or CUDA.
  4. Use Test or Clone/Test to verify voices.

Example: TTS Source From Chat

  1. Enable a TTS model and verify that it is running.
  2. In Overlay Setup, add a TTS source to a box.
  3. Select a voice and set Message to {{message.text}}.
  4. Bind the box to a command trigger such as !tts.
  5. When the command arrives, NekoBot resolves the trigger tokens and generates the audio source.
