Setup

Download & Install

Use the latest release package from GitHub Releases.

Install Steps

  1. Download the latest release from GitHub Releases.
  2. Extract the package into a folder you control.
  3. Run NekoBot_LLM.exe.
  4. Use the tray icon to open Setup Home.

First Run

NekoBot creates its local data and settings files when it starts. A fresh install should not require pre-existing overlay or TTS configuration files.

Setup Home

After launch, open Setup Home from the tray. This page is the public entry point for every setup area.
