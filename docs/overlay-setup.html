Overlays

Overlay Setup

Overlays define where boxes live, how they look, and what sources can be shown when triggers arrive.

Basic Flow

  1. Create a new overlay.
  2. Add boxes to reserve screen space.
  3. Add sources such as text, media, URL, or TTS.
  4. Bind triggers to boxes.
  5. Copy the overlay URL into OBS as a browser source.

Viewer

The Open Overlay page lets you choose an overlay and preview the actual viewer. OBS should use the copied overlay URL for the layout you want to show.

Example: Add a Chat Message Box

  1. Create or select an overlay.
  2. Click Add box and position the box on the stream preview.
  3. Add a Text source with a message like {{message.text}}.
  4. Open Trigger and add a chat-message trigger.
  5. Save the overlay and copy the OBS URL.

Example: Multi-Source Rotation

For boxes with more than one source, use source trigger mode to decide which source appears.

  • Random picks one source while avoiding the same source twice in a row when possible.
  • Sequence moves through the source list and wraps around at the end.
  • Custom evaluates rules against trigger values and chooses the matching source.
